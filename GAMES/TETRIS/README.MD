# TETRIS FOR DOS

## What's new
 * v1.1: built on TMGDL 1.5 (millisecond timer, 32-bit scores on 16-bit
   builds); plays in 160 x 100 pixels, 16 colours (LIBTEXT lores API),
   with shaded blocks
 * v1.0: initial release

## Compiler
 * Turbo/Borland Pascal 7.0
 * TMT Pascal 3.9+
 * Free Pascal 3.2 (go32v2)
